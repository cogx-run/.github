## 🌟 我们在做什么？

在商业软件越来越臃肿、数据越来越私有化的时代，**CogX** 致力于把桌面的主权交还给用户：

- 🕊️ **治愈陪伴**：官方买断制叙事游戏《莫尔：桌面旅人》，陪伴你的每一次专注。
- ⚡ **AI 零秒直出**：复制任意大模型写出的单文件代码，剪贴板一键导入，0 秒桌面运行。
- 📦 **轻量替代**：以几十 KB 的极简插件，替代待办、便签、盯盘等几百兆的庞大软件。

## 💡 我们的原则

1. **本地优先（Local-First）**：所有数据明文存放在你电脑的 `.cogx/` 目录，无强制云端锁定，天然支持 Git 同步。
2. **拒绝构建（Zero-Build）**：依托原生 Web ESM 标准，无需配置 Node.js 打包链，写一个 `main.js` 就能跑。
3. **独立安全岛**：设置面板与插件运行物理进程隔离，主台卡死仍可秒开熔断。
