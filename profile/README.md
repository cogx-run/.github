## 💡 CogX 是什么？

一个跑在你自己电脑上的轻量桌面扩展坞。内核本身不提供任何具体功能——时钟、便签、番茄钟、盯盘、桌宠、迷你游戏，全部以插件形式存在，随用随开，关掉即释放。

它同时也是一套 **插件标准** ：`meta` 声明能力，`ctx` 提供系统接口，工作区 `.cogx/` 存明文数据。任何人都可以照着写插件、做发行版、建自己的商店。

---

## 🌟 五大核心理念

### 1. 一个文件就是一个插件。

基于现代浏览器 ESM 标准，**无需配置打包环境，无需构建等待，仅需一个 `main.js` 即可直接运行**。
小到便签、盯盘与番茄钟，大到深度叙事游戏，在微内核中地位完全平等。它可以当工具台、桌宠营地、迷你游戏盒，也可以是 AI 生成单文件小应用的运行底座。

### 2. AI 写完，粘贴即运行。

把需求丢给任何顺手的大模型，按官方 Prompt Protocol 生成代码，复制，在设置页点「从剪贴板导入」——挂件直接出现在桌面上。生成物只是工作区里一个明文文件，属于你，随时能改、能带走。

### 3. 数据在你自己的文件夹。

配置、插件源码、个人数据全部以明文 JSON / Markdown / JS 保存在你选定的工作区 `.cogx/` 目录。用 Git 管版本、放网盘、拷进 U 盘都随你。不注册能用，断网也能用。

### 4. 极致轻量，关掉即释放。

底层由 **Rust + 系统原生 WebView** 构建，不背传统架构数十上百兆的常驻开销。权限只保留两道真实边界——网络出口与工作区路径，其余能力交给用户与开发者自行判断。

### 5. 开源微内核，去中心化生态共享。

底座微内核全面开源（Apache-2.0），代码开放即是标准普及。凡是基于 CogX 契约开发或分发的应用，插件生态完全共享互通。

## 🕊️ CogX 名字的由来

> _“风停雾聚，你在桌前歇息；风起雾散，他开始跋涉群山。”_
> _“你在现实世界努力，他在异世界远行。”_

名字源于原创叙事伴侣游戏《莫尔：桌面旅人》：

- **机械鸟：考格（Cog，意为齿轮）**：
  在故事中，考格是一只在遗忘之雾中意外觉醒智能的黄铜机械鸟。
  在莫尔醒来时，考格穿过大雾飞来，从此成为他的忠实伴侣；它身上隐藏着莫尔的身世之谜。
- **无限（X）**：
  代表未知、灵感火花与去中心化插件生态的无限扩展。
- **信差：莫尔（More）**：
  名字取自 _“One more step”_（再走一步）。代表在疲惫的生活与工作中，安静陪你再坚持往前多走一段路。

**一枚齿轮咬合万千插件，一羽铜鸟陪伴每一个工作日常。**
