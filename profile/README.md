## 💡 CogX 是什么？

**一句话定义：基于本地文件系统与原生现代 Web 标准的轻量级微内核副屏容器。**

它是安静常驻于屏幕一隅的万能轻空间：
**从 AI 生成的单文件小挂件，到外部现代 Web 网页，再到完整的独立游戏——在底层一切皆是插件，随用随开，随关随释放。**
告别动辄数百兆、强捆绑登录的臃肿独立软件，找回桌面本该拥有的清爽与自由。

---

## 🌟 五大核心理念

### 🧩 1. 一切皆插件 · 零构建开发

基于现代浏览器原生 ESM 标准，**无需配置打包环境，无需构建等待，仅需一个 `main.js` 即可直接运行**。
小到便签、盯盘与番茄钟，大到深度叙事游戏，在微内核中地位完全平等。它是你的常用工具台、副屏桌宠、迷你游戏盒与启动台，更是 AI 生成单文件小应用的绝佳运行底座。

### ⚡ 2. AI 对话秒级直出 · 剪贴板导入即运行

**彻底告别配置运行环境的繁琐**。把需求丢给任何大语言模型，点击复制代码，在 CogX 设置面板中点击 **“从剪贴板导入”**——挂件 1 秒直接在桌面上运行起来。

### 📂 3. 本地优先 · 100% 数据主权

**一切基于本地文件，绝不强制注册与联网**。所有配置、插件与个人笔记以明文保存在你选定工作区的 `.cogx/` 目录中。你可以完全自由地使用 Git、U 盘、网盘乃至 Steam Cloud 实现无感同步。

### 🪶 4. 极致轻量 · 内存秒级释放

底层由 **Rust + 系统原生 WebView** 构建，拒绝传统架构数十上百兆的常驻开销。搭配二元权限网关，在保证隐私安全的同时，做到插件随用随开、随关随走，内存秒级回收。

### 🕊️ 5. 开源微内核 · 去中心化生态共享

底座微内核全面开源（Apache-2.0），代码开放即是标准普及。凡是基于 CogX 契约开发或分发的应用，插件生态完全共享互通。

## 🕊️ CogX 名字的由来

> _“风停雾聚，你在桌前歇息；风起雾散，他开始跋涉群山。”_
> _“你在现实世界努力，他在异世界远行。”_

名字源于原创叙事伴侣游戏《莫尔：桌面旅人》：

- **信差：莫尔（More）**：
  名字取自 _“One more step”_（再走一步）。代表在疲惫的生活与工作中，安静陪你再坚持往前多走一段路。
- **机械鸟：考格（Cog，意为齿轮）**：
  在故事中，考格是一只在遗忘之雾中意外觉醒智能的黄铜机械鸟。
  在莫尔醒来时，考格穿过大雾飞来，从此成为他的忠实伴侣；它身上隐藏着莫尔的身世之谜。
- **无限（X）**：
  代表未知、灵感火花与去中心化插件生态的无限扩展。

**一枚齿轮咬合万千插件，一羽铜鸟陪伴每一个工作日常。**
